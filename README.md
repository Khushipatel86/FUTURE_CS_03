# API Security Risk Analysis using Postman

## Project Overview
This project focuses on analyzing security risks in web APIs using Postman. APIs are widely used for communication between applications, but if they are not properly secured, attackers can exploit them to access or manipulate sensitive data. The aim of this task is to understand common API vulnerabilities and test how security mechanisms protect endpoints.

## Objective
- Test API endpoints using Postman  
- Identify possible security weaknesses  
- Understand authentication and authorization handling  

## Tests Performed
During the assessment, multiple checks were performed, such as:
- Access without authentication  
- Invalid or expired tokens  
- Parameter manipulation  
- Method testing (GET, POST, PUT, DELETE)  

## Risks Observed
The analysis highlights how improper validation, weak authentication, or missing access control can expose systems to unauthorized access and data leakage.

## Tools Used
- Postman for sending API requests  
- Manual inspection of responses  
- Screenshot documentation  

## Outcome
This project improved practical knowledge of API security testing and awareness of how to secure endpoints effectively.
